# 校园寻宝现场手工 QA 清单

所有条目都需要在目标展会电脑上实际执行并记录证据；本清单保持未勾选，不能替代自动化测试。

## 源项目启动

- [ ] 在项目根目录使用 Godot 4.6.3 执行 `--headless --import --path .`，确认导入完成且无资源错误。
- [ ] 导入完成后从 Godot GUI 打开并运行 `res://src/main/main.tscn`，确认根节点为 Main 且标题画面出现。

## 显示与缩放

- [ ] 1280×720 全屏运行，画面保持 16:9，必要时只出现黑边且无拉伸。
- [ ] 1366×768 全屏运行，画面保持 16:9，黑边位置正确且像素边缘清晰。
- [ ] 1920×1080 全屏运行，画面保持 16:9，黑边位置正确且像素边缘清晰。

## 移动、碰撞与寻宝

- [ ] WASD 四键分别移动，松键立即停止且不会卡住。
- [ ] 方向键四键分别移动，松键立即停止且不会卡住。
- [ ] 按住单个方向键持续移动，速度稳定且不会自动改变方向。
- [ ] 同时按相反方向键，确认不会穿过墙体或出现异常抖动。
- [ ] 同时按相邻方向键，确认对角移动可用且速度稳定。
- [ ] 撞击墙体时玩家停在碰撞边界，未穿墙。
- [ ] 走到地图四条边缘时玩家被限制在地图内。
- [ ] 将目标放在上、下、左、右四个方位，右上角箭头分别显示四个正确的 cardinal 方向。
- [ ] 将目标放在四个对角方位，右上角箭头分别显示四个正确的 diagonal 方向。
- [ ] 目标距离为 0 m 时显示 `0 m`。
- [ ] 目标距离为 1 m 时显示 `1 m`。
- [ ] 目标距离为 18 m 时显示 `18 m`。
- [ ] 目标距离为 23 m 时显示 `23 m`。
- [ ] 连续游玩多轮（含自动重开），每次找到宝箱后玩家保持原地，确认全程没有传送。

## 命数与终局

- [ ] 标题画面与结束画面期间左上角不显示心形；按移动键开始后左上角出现 3 颗满心。
- [ ] 点击错误答案后左上角立即减少 1 颗心（变空心），2 秒反馈结束后再刷新下一个宝箱进入下一轮。
- [ ] 连续答错 3 次后命数耗尽，显示“挑战失败，命数耗尽”覆盖层，不刷新下一个宝箱。
- [ ] 失败覆盖层显示约 3 秒后自动回到标题画面，下一位玩家按移动键可开始新的一轮，且命数恢复为 3 颗满心、第 1 题回到题库第 1 题。
- [ ] 答对 1 次后显示“回答正确，请领取奖品”并持续 4 秒庆祝，随后自动回到标题画面，不刷新下一个宝箱。
- [ ] 胜利或失败期间玩家保持原地，确认不传送。

## AI 答题与领奖

- [ ] 触碰宝箱后角色立即停止移动、导航隐藏，旧宝箱未提前替换，中央答题面板完整显示题目和 A、B、C、D 四个选项。
- [ ] 尝试使用数字键 `1–4`、字母键 `A–D` 和回车选择答案，确认均无效；仅鼠标点击选项有效。
- [ ] 答题面板打开时，确认底部显示“请选择一个答案（仅 1 次机会）”。
- [ ] 第一次点击错误答案，确认该选项变红、四个选项全部禁用并显示“挑战失败，本轮无奖”，且不出现领奖庆祝。
- [ ] 答错结算后尝试点击正确答案，确认不会进入领奖庆祝。
- [ ] 第一次直接点击正确答案，确认同样只进入一次领奖庆祝，不会生成多个宝箱。
- [ ] 等待失败提示 2 秒，确认答题面板关闭、新宝箱只生成一个、角色恢复移动且导航指向新目标。
- [ ] 在已结算的选项上重复点击，确认不会重复失败、重复领奖、跳题或生成多个宝箱。
- [ ] 分别走通一次答对和一次答错路径，确认两种路径都保持玩家原地不传送。
- [ ] 在 640×360 逻辑画布及 1280×720 实际显示下检查最长题目和最长选项，确认文字完整可读、四个按钮无重叠或越界。
- [ ] 检查鼠标悬停、答错、答对和全部禁用状态，确认颜色对比清晰且反馈含义明确。

## 窗口焦点与恢复

- [ ] 在寻宝、答题、2 秒失败反馈、4 秒庆祝和 3 秒结束等待期间分别切换到其他窗口，确认失去焦点后玩家与三个计时器都停止。
- [ ] 切回游戏窗口，确认恢复焦点后游戏继续且流程只恢复一次。
- [ ] 若现场画面或流程异常，按 `Alt+F4` 退出并按 README 的源项目步骤重新启动，确认玩家回到中央广场并生成首个宝箱。

## 静音与内容边界

- [ ] 全程无声音或音频设备访问。
- [ ] 全程无网络请求。
- [ ] 画面和日志中无品牌内容、兑换码、玩家姓名、计数器或排行榜（左上角命数心形除外）。

## 现场性能与首次体验

- [ ] 记录 10 位首次玩家从开始到找到首个宝箱的完成时间，并计算完成时间不超过 180 秒的百分比。
- [ ] 在展会电脑以 1280×720 运行，观察完整寻宝流程并确认稳定 60 FPS。
