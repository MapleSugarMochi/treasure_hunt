# 《校园寻宝》爱心 UI 替换设计

日期：2026-08-13  
状态：已批准

## 目标

以 `assets/generated/heart.jpg` 作为唯一爱心来源，替换当前由 `ui.png` 图集绘制的生命爱心。源图为 2400×2400、无透明通道的 JPEG；游戏中每个生命槽位保持现有 16×16 像素布局。

## 方案

- 保留原始 `heart.jpg`，不覆盖、不拉伸后直接用于运行时 UI。
- 在现有美术生成脚本中，从原图裁出爱心主体、将棋盘背景转换为透明、等比缩放为 16×16 的无抗锯齿 PNG。
- 生成 `assets/generated/heart-full.png`，用于剩余生命；从同一爱心生成 `assets/generated/heart-empty.png`，降饱和、降低亮度，作为已扣除生命的灰暗状态。
- `GameUI` 改为直接在三个现有 `TextureRect` 槽位上切换上述两张贴图；槽位的位置、数量与可见性规则不变。
- 移除对 `ui.png` 中旧爱心图集区域的运行时依赖；导航箭头和庆祝粒子继续使用该图集，图集尺寸与其他区域不改变。

## 验收

- 满命显示三颗来自 `heart.jpg` 的红色爱心；失去生命后对应爱心显示相同轮廓的灰暗版本。
- 两张运行时贴图均为 16×16、包含透明背景、使用最近邻采样，不显示原图棋盘。
- 现有标题、答题、胜利、失败与自动换人流程不变。
- 自动测试验证满命/失命的纹理切换和贴图尺寸；完整测试及美术校验通过。
