# 《校园寻宝》爱心图标边缘修复设计

日期：2026-08-13
状态：已批准

## 目标

直接逐像素重绘并覆盖 `assets/generated/heart-full.png` 与 `assets/generated/heart-empty.png`，保持 16×16 清晰像素风硬边，修复透明孔洞、孤立像素与断裂边缘。

## 方案

- 不修改 `tools/generate_art.gd`，也不再从 `heart.jpg` 自动提取运行时爱心。
- 两张 PNG 使用同一套手绘 Alpha 剪影：左右双圆弧、中央凹口和逐级收窄的底部尖角。
- 满心使用深色一像素描边、红色主体、左上浅色高光和右下暗红阴影。
- 空心状态沿用完全相同的 Alpha 剪影，将每个不透明像素映射为对应灰度层次。
- 所有像素 Alpha 只能为 0 或 255，不加入抗锯齿、发光或软阴影。

## 验收

- 两张图均为 16×16 RGBA PNG，并含透明边距。
- 不透明区域各自只有一个连通主体，内部不存在透明孔洞。
- 两张图的 Alpha 蒙版逐像素一致。
- 满心保留深色描边、红色填充、浅色高光和暗红阴影；空心全部为灰度色。
- 不改变生命数量、UI 布局、资源路径或游戏逻辑。

## 不在本次范围

- 不修复或扩展 JPEG 前景提取与缩放算法。
- 不修改其他生成图集、地图资源或世界逻辑。
