# 《校园寻宝》爱心图标边缘修复设计

日期：2026-08-13
状态：待实施

## 问题与根因

`assets/generated/heart.jpg` 是带有烘焙棋盘格背景的 JPEG，而不是带透明通道的源图。当前 `tools/generate_art.gd` 仅按红色与深色阈值识别爱心前景，因此会把爱心内部的白色、浅粉色高光误判为背景。随后从高分辨率裁剪图直接使用最近邻缩小到 16×16，又会因采样位置与源图像素块网格未对齐而漏掉部分一像素描边。最终生成的 `heart-full.png` 与 `heart-empty.png` 存在内部透明孔洞、孤立像素和断裂边缘。

## 目标

- 继续输出 16×16 RGBA PNG，并保持清晰的像素风硬边。
- 所有像素只能完全透明或完全不透明，不引入半透明抗锯齿。
- 保留源爱心的红色填充、深色描边、浅色高光与右侧阴影。
- 外轮廓连续，内部没有因前景提取造成的透明孔洞或断边。
- `heart-full.png` 与 `heart-empty.png` 使用完全相同的 Alpha 剪影。
- 不改变生命数量、UI 布局、资源路径或游戏逻辑。

## 方案

### 1. 前景提取

从裁剪区域边界开始，对接近棋盘格灰白色的像素执行背景连通遍历。只有与裁剪边界连通的棋盘格像素才作为背景；被爱心轮廓包围的白色和浅粉色高光仍作为前景保留。

深色描边和红色主体继续作为确定前景，用于定位爱心边界，并防止 JPEG 压缩噪点把背景连接进主体。

### 2. 像素量化

不再依赖单点最近邻抽样决定目标像素。将裁剪区域划分为 16×16 个覆盖单元，根据每个单元内的前景覆盖率决定目标 Alpha，再从该单元的前景像素中选取代表色。代表色保持硬边与源图主要颜色层次，不做双线性插值。

量化后执行局部拓扑清理：

- 填补被不透明像素包围、且来自前景覆盖的内部透明孔洞。
- 去除不与主体连通的孤立不透明像素。
- 修补因量化造成的单像素描边断点，但不扩大整体图标边界。

### 3. 空心状态

`heart-empty.png` 继续从修复后的 `heart-full.png` 派生，只调整不透明像素的颜色。Alpha 值逐像素复制，确保两个状态的轮廓完全一致。

## 验证

扩充 `tools/validate_art.gd` 的爱心校验：

- 两张图均为 16×16 RGBA。
- Alpha 只能为 0 或 255。
- 两张图的 Alpha 蒙版逐像素相同。
- 不透明前景只有一个连通主体，不存在孤立像素。
- 主体包围区域内不存在透明孔洞。
- 满心仍包含红色像素；空心的所有不透明像素仍为灰度色。

运行完整自动化测试与美术校验，并以放大后的最近邻预览人工确认：轮廓连续、高光完整、边缘无杂色、两种状态切换时剪影不跳动。

## 不在本次范围

- 不重画新的爱心造型。
- 不增加平滑抗锯齿、发光、阴影或动画。
- 不修改 `GameUI` 的生命逻辑与三个爱心槽位。
- 不处理其他生成图集或当前未跟踪的地图资源。
