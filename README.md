# 校园寻宝

## 现场启动（Godot 源项目）

项目使用 Godot 4.6.3。请在项目根目录打开 PowerShell，先完成一次资源导入，再从 Godot GUI 运行源项目：

```powershell
& '.superpowers\toolchains\godot-4.6.3\Godot_v4.6.3-stable_win64_console.exe' --headless --import --path .
& '.superpowers\toolchains\godot-4.6.3\Godot_v4.6.3-stable_win64.exe' --path .
```

上面的第一条命令必须先执行；第二条命令打开 Godot 的源项目运行窗口。本阶段不提供独立游戏打包文件，也不需要寻找或启动游戏 EXE。

## 操作

- 使用 WASD 或方向键移动；第一次按移动键会从标题画面开始一轮寻宝。
- 触碰宝箱后，使用鼠标点击一个答案；键盘不能选择答案。
- 每道题最多回答 2 次。第一次答错后还可再选一次；第二次仍答错则本轮无奖。
- `Alt+F4` 退出运行窗口。
- 窗口失去焦点时游戏会暂停，恢复焦点后继续；如果画面异常，按 `Alt+F4` 退出并再次执行上面的源项目启动命令。项目不保存玩家进度，重新启动会把玩家放回中央广场并生成首个宝箱。

## 正常表现

- 右上角箭头精确指向当前宝箱，支持四个方位和四个对角方向；目标变化后箭头会更新。
- 距离是玩家到宝箱的直线距离，并显示为整数米数。
- 找到宝箱后角色停止移动并显示一道 AI 四选一题；10 道题按顺序出现，第 11 轮回到第 1 题。
- 第一次答错会把错误选项标红并提示还剩 1 次机会；第二次答错显示“挑战失败，本轮无奖”，2 秒后进入下一轮。
- 答对后显示“回答正确，请领取奖品”，庆祝动画持续 4 秒，随后自动进入下一轮。
- 无论答对或连续两次答错，玩家都保持原地不传送，新宝箱会在结算后生成。
- 全程静音，不访问网络，不显示品牌、玩家姓名、代码、计数器或排行榜。
